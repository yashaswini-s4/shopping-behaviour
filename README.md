# shopping-behaviour
Shopping Behaviour Analysis project using real customer purchase data to explore spending trends, product preferences, and demographic influence on buying decisions.
This project analyzes customer shopping behaviour using real purchase data to uncover insights about spending trends, product preferences, demographics, and customer segments. The goal is to understand key patterns that influence buying decisions and help support data-driven decisions in the retail sector.

📌 Project Objectives

Analyze customer purchase history and demographics

Identify patterns in product categories, shopping seasons, and spending habits

Visualize behavioural trends using charts and dashboards

Derive insights to support marketing and retail business strategies

🧠 Key Steps in the Project

✔ Importing and cleaning the dataset
✔ Handling missing values & encoding categorical variables
✔ Statistical analysis and aggregation
✔ Visualizing trends (spending, categories, seasonality, gender split, etc.)
✔ Identifying customer segments and behaviour insights

🛠️ Tech Stack
Component	Tools Used
Programming	Python
Data Analysis	Pandas, NumPy
Visualization	Matplotlib, Seaborn, Plotly
Machine Learning 	Scikit-learn (Clustering / Prediction)
IDE	Jupyter Notebook / Google Colab
